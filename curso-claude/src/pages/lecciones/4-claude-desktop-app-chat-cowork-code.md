# 🖥️ Claude Desktop App: Chat, Cowork y Code
## Una Experiencia Nativa para Potenciar tu Productividad

---

# 🚀 Introducción al Ecosistema de Escritorio
La aplicación de escritorio de Claude te ofrece tres modos de interacción diseñados para adaptarse a cada tipo de tarea: desde preguntas rápidas hasta investigación compleja y desarrollo de software.

1.  **Chat:** La experiencia conversacional mejorada con funciones nativas.
2.  **Cowork:** Una herramienta agencial para proyectos que requieren autonomía y stamina.
3.  **Code:** Un entorno de desarrollo completo para escribir, probar y desplegar código.

> [!NOTE]
> **Cowork** y **Code** funcionan sobre el mismo motor agencial (**Claude Code**). Esto les permite trabajar de forma independiente, lanzar sub-agentes y mantener tareas de larga duración en segundo plano.

---

# 💬 Modo Chat: Agilidad Diaria
El Chat destaca cuando necesitas hacer preguntas, generar ideas, redactar borradores o resolver problemas mediante el diálogo.

### ✨ Funciones Nativas de Escritorio:
*   **🎹 Quick Entry (Acceso Rápido):** Pulsa dos veces la tecla `Option` (Mac) para abrir Claude sobre cualquier app. Responde en una ventana compacta que se mantiene siempre al frente.
*   **📸 Capturas de Pantalla:** Comparte una ventana o captura instantáneamente para que Claude "vea" lo que tú ves. (Mac)
*   **🎙️ Dictado:** Habla con Claude cuando pensar en voz alta sea más rápido que escribir. (Mac)
*   **🔗 Conectores de Escritorio:** Enlaza herramientas y servicios locales directamente desde tu máquina.

---

# 🤝 Modo Cowork: Tu Compañero de Trabajo Agencial
Diseñado para tareas que requieren un esfuerzo real: extraer información de múltiples fuentes, procesarla y generar un entregable final pulido.

### 🛠️ Capacidades de Cowork:
*   **Multitarea:** Claude puede abordar diferentes partes de un proyecto a la vez.
*   **Planificación Automática:** Antes de empezar, Claude suele hacer preguntas clave para definir el alcance y construye un plan que puedes revisar en la barra lateral.
*   **📁 Acceso a Carpetas:** Apunta a una carpeta local; Claude leerá lo relevante y guardará el trabajo final en esa misma ubicación.
*   **📅 Tareas Programadas:** Automatiza rutinas (ej. resumen diario de Slack y calendario). Claude lo maneja solo mientras la app esté abierta.

---

# 🌐 Funciones Avanzadas de Cowork

*   **🕵️ Sub-agentes:** Trabajadores en segundo plano que Claude crea para manejar partes de una tarea en paralelo (ej. investigar múltiples fuentes a la vez).
*   **📱 Dispatch:** Continúa tus conversaciones de Cowork desde el móvil. Puedes dar tareas a Claude que usen tus archivos locales incluso si no estás frente al PC.
*   **🌍 Navegación Web (Chrome):** Claude puede navegar por sitios, interactuar con páginas y extraer datos (ej. comparar precios en 10 sitios diferentes).
*   **🖱️ Computer Use:** Si no hay un conector, Claude puede navegar por tu ordenador (clic, escribir, abrir apps) como lo harías tú. *(Preview en Mac, Windows próximamente)*.

---

# 💻 Modo Code: Desarrollo de Software Agencial
Acceso directo a la potencia de **Claude Code** para construir software de extremo a extremo.

### 🏗️ Entornos de Trabajo:
*   **Local:** Claude trabaja con tus archivos locales, accede a tus herramientas y puede ejecutar un servidor de desarrollo para previsualizar en el navegador.
*   **Remote:** Conecta un repositorio de GitHub y Claude trabajará en un entorno en la nube. Las sesiones continúan incluso si cierras la app.

### 🕹️ Modos de Interacción:
*   **Ask:** Claude propone cada cambio y espera tu aprobación visual (diff).
*   **Code:** Aplica cambios en archivos automáticamente (pide permiso para comandos de terminal).
*   **Plan:** Esboza la estrategia completa en un visor dedicado antes de tocar el código.

# 📊 Comparativa de Modos

| Característica | 💬 Chat | 🤝 Cowork | 💻 Code |
| :--- | :--- | :--- | :--- |
| **Optimizado para** | Intercambios rápidos, ideas y aprendizaje. | Tareas complejas, análisis y documentos finales. | Construir software, testear y desplegar. |
| **Funciones Clave** | Quick entry, dictado. | Acceso a carpetas, sub-agentes, tareas programadas. | Modos Ask/Code/Plan, Git, entornos remotos. |
| **Herramientas** | Conectores, Skills. | Conectores, Plugins, Computer Use. | Plugins, Hooks, Terminal Full. |

---

# 💡 ¿Cuándo usar cada modo?
*   **Chat:** "Doble clic en `Option`, captura la pantalla de un dashboard confuso y pregunta: *¿Qué significan estas métricas?*"
*   **Cowork:** "Revisa lo que decidimos sobre precios en notas de reuniones, Slack y emails, y actualiza nuestra presentación del Q3 con los hallazgos".
*   **Code:** "Selecciona la carpeta de tu proyecto y pide: *Implementa una nueva API de autenticación y añade tests unitarios*".

---

# 🔒 Seguridad y Privacidad
*   **Entorno Protegido:** Cowork y Code se ejecutan en espacios contenidos. Claude solo accede a las carpetas que tú autorices explícitamente.
*   **Control de Aplicaciones:** Recibirás una solicitud de permiso antes de que Claude acceda a cada aplicación (Computer Use).
