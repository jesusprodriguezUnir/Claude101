# 🌐 Otras Formas de Trabajar con Claude
## Claude en tus Herramientas Favoritas

---

# 🚀 Una Inteligencia, Múltiples Interfaces
Claude es una inteligencia omnipresente. Aunque `claude.ai` es la forma más común de usarla, también está disponible en herramientas especializadas diseñadas para integrarse en tu flujo de trabajo actual.

Esta lección introduce cinco formas adicionales de trabajar con Claude, cada una adaptada a casos de uso específicos.

---

# 💻 Claude Code
Es una herramienta agencial para desarrolladores que funciona en tu terminal, IDE, navegador o incluso Slack. Entiende tu base de código, ejecuta comandos y maneja flujos de desarrollo completos.

### Cuándo usar Claude Code:
*   **Construcción Agencial:** Describe lo que necesitas y deja que Claude escriba el código, pase los tests y haga los *commits*.
*   **Debugging:** Pega un error y deja que Claude analice tu repositorio para encontrar la causa raíz.
*   **Navegación:** Haz preguntas sobre cómo interactúan diferentes partes de un código complejo o desconocido.
*   **Automatización:** Corrige errores de *lint*, resuelve conflictos de *merge* o redacta notas de lanzamiento automáticamente.

---

# 💬 Claude en Slack
Integración directa para colaborar con tu equipo en tiempo real.

### Cuándo usar Claude en Slack:
*   **Resúmenes:** Resume hilos largos o discusiones complejas sin salir de Slack.
*   **Preparación de Reuniones:** Pide a Claude que reúna conversaciones y documentos compartidos antes de una reunión.
*   **Onboarding:** Ayuda a nuevos miembros a entender proyectos revisando el historial de canales.
*   **Pase de Tareas:** Etiqueta a `@Claude` en un reporte de error para que inicie una sesión de Claude Code con ese contexto.

---

# 📊 Claude para Excel y PowerPoint

### 📈 Claude para Excel (Barra Lateral)
Analiza y modifica hojas de cálculo mediante conversación.
*   **Entendimiento:** Explica fórmulas complejas en libros con múltiples pestañas.
*   **Depuración:** Rastrea y corrige errores como `#REF!` o referencias circulares.
*   **Modelado:** Crea proyecciones financieras preservando las dependencias.

### 📽️ Claude para PowerPoint (Barra Lateral)
Redacta y edita presentaciones manteniendo tu estilo de marca.
*   **Borradores:** Convierte notas o documentos en un primer borrador de diapositivas.
*   **Edición:** Ajusta el tono, acorta viñetas y añade notas del orador.
*   **Formato:** Aplica estilos consistentes a todo el mazo de diapositivas automáticamente.

---

# 🌐 Claude para Chrome
Extensión de navegador que actúa como un asistente lateral inteligente.

### Cuándo usar Claude para Chrome:
*   **Investigación Web:** Resume artículos, papers o páginas mientras navegas.
*   **Gestión de Inbox:** Ayuda a redactar respuestas de email y gestionar tu bandeja de entrada.
*   **Automatización:** Rellena formularios repetitivos y navega flujos de varios pasos.

> [!IMPORTANT]
> **Nota de Seguridad:** Claude para Chrome está en fase de investigación. Anthropic recomienda usarla para tareas de bajo riesgo en sitios de confianza. Ciertas categorías (finanzas, contenido adulto) están bloqueadas por defecto.
